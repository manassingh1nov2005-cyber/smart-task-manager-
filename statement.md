# Smart Task Manager – Project Statement

## 1. Problem Statement

Managing daily tasks manually can be difficult, especially when users have multiple tasks to remember, complete, and track. Without a proper task management system, users may forget important tasks or lose track of their progress.

The **Smart Task Manager** is a Java-based command-line application designed to provide a simple and efficient way to manage daily tasks. It allows users to add, view, complete, and delete tasks through a menu-driven interface. The application also provides persistent file storage so that tasks can be saved and accessed even after the program is closed.

The project aims to demonstrate how core Java programming concepts such as **classes and objects, Object-Oriented Programming, ArrayList, loops, conditionals, file handling, and user input** can be combined to solve a real-world problem.

---

## 2. Scope of the Project

The scope of the Smart Task Manager includes developing a lightweight command-line application for basic personal task management.

The project covers:

- Creating and storing tasks.
- Viewing all available tasks.
- Marking tasks as completed.
- Deleting tasks when they are no longer required.
- Providing a menu-driven command-line interface.
- Storing tasks in a file for persistent data management.
- Using Java collections such as `ArrayList` for managing multiple tasks.
- Applying Object-Oriented Programming principles to organize the application.

The current project focuses on **local task management through a Java CLI**. Advanced features such as graphical interfaces, cloud synchronization, user authentication, notifications, and multi-user collaboration are outside the current scope but can be considered for future development.

---

## 3. Target Users

The Smart Task Manager is primarily designed for:

- **Students** – to manage assignments, study tasks, projects, and daily activities.
- **Working Professionals** – to keep track of work-related tasks and responsibilities.
- **Individuals** – to organize personal daily activities and to-do lists.
- **Beginners learning Java** – to understand how Java concepts can be applied to a practical application.

The application is particularly suitable for users who prefer a **simple and lightweight task management system without the complexity of a graphical application**.

---

## 4. High-Level Features

### 4.1 Add Task
Users can create a new task by entering the required task details. The task is stored in the task collection.

### 4.2 View Tasks
Users can view all currently stored tasks along with their completion status.

### 4.3 Mark Task as Completed
Users can select a task and change its status from pending to completed.

### 4.4 Delete Task
Users can remove a task that is no longer required.

### 4.5 Menu-Driven Interface
The application provides a simple menu through which users can select different task-management operations.

### 4.6 Persistent Storage
Tasks can be saved to a local file so that the task information is not lost when the application is closed.

### 4.7 Object-Oriented Design
The project uses separate classes such as `Task` and `TaskManager` to organize task data and task-management operations.

### 4.8 Collection-Based Task Management
An `ArrayList` is used to dynamically store and manage multiple task objects.

---

## Project Objective

The primary objective of the Smart Task Manager is to develop a simple, reliable, and easy-to-use task management application while demonstrating the practical implementation of fundamental Java programming and Object-Oriented Programming concepts.
